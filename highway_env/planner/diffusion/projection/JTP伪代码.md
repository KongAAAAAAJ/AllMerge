# JTP Stage 3：道路活动集降采样与逐约束非退化接受

1. 计算名义控制序列的控制范围残差和六类状态约束残差。若控制范围满足硬约束且所有状态约束满足各自容差，则原样返回。
2. 仅根据六类状态约束的初始超容差残差与重要性权重计算优先级分数 `q * (1 + max(excess))`，排序后固定划分为 2 或 3 组。控制量范围不参与排序、评分或活动集截断。
3. 在一次 `project()` 调用中预计算 K2 条件矩阵、初始潜状态与潜空间敏感度。
4. 道路 LS 候选仅取每辆车未来每两个 step 的中心轮廓圆心，并计算左右边界残差，得到每辆车 40 条候选；三车合计最多 120 条，再按全局 Top-K=30 选入 LS。道路完整五圆心、40步残差仍保留用于非线性接受和最终指标。碰撞约束不降采样。每次外层迭代计算一次共享输出敏感度、状态活动约束 Jacobian 和目标度量矩阵 `M`。`M` 仅进行一次 Cholesky 分解。
5. 首先求解控制范围硬约束的最小度量修正，使累计控制量进入可执行范围。随后按优先级依次求解状态约束组。每组线性残差为 `r = c - tau + Jp`，其中 `tau` 与非线性评价使用同一容差张量。每个组子问题都同时满足最终控制量范围和累计信赖域约束。无约束步采用加权 Gram Cholesky 求解；信赖域超限时先增加内部阻尼重新求解，剩余活动边界由降维原始 Cholesky 活动集求解。之后通过度量半空间投影保护前序组已选活动行，并同时保持控制范围和信赖域可行。
6. 对未经逐元素截断的候选控制序列执行回溯线搜索。一次线搜索期间冻结道路关联，所有候选均使用相同约束行对应关系。候选必须满足控制范围硬约束；每个优先级组内所有状态约束行的超容差违反程度均不得增加，且该组违反约束数量不得增加。至少一条状态约束获得超过改进阈值的改善，或某组违反数量减少，候选才具备状态投影进展。若输入控制原本超出硬范围，允许在所有状态约束均不退化且违反数量不增加的前提下接受硬约束恢复。候选被接受后，使用其 K2 rollout 重新计算最近道路关联，供下一次外层迭代使用。
7. 满足约束或达到迭代预算、信赖域下限、停滞上限时，返回最后接受的控制序列及对应执行预测，并保留约束满足标志。

Stage 3 在 Stage 1 的有界阻尼最小二乘、Cholesky 活动集和前序组半空间保护基础上，不调用外部通用 QP 求解器。道路 LS 活动候选采用中心圆心每两个 step 采样、全局 Top-K=30；完整道路验证仍使用五圆心和40步。各物理约束定义见 `JTP约束定义.md`。
