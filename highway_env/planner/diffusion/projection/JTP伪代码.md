# JTP Stage 1：优先级分组 LS 与非退化保护

1. 计算名义控制 U0 的全部归一化约束残差。若已可行，原样返回。
2. 根据各约束族初始最大正残差 epsilon 与重要性 q，计算 T=q(1+epsilon)，排序并固定划分为 2 或 3 组。
3. 在一次 project 调用中预计算 K2 条件矩阵、初始潜状态与潜空间敏感度。
4. 每次外层迭代计算一次共享输出敏感度、活动约束 Jacobian 和目标度量 M；M 仅 Cholesky 分解一次。
5. 令 p=0。按优先级依次求解：计算当前组线性残差 r=c+Jp，选取正残差；以原阻尼加权 Gram Cholesky 方法求 d。对 d 顺序投影至前组活跃约束半空间 J_H d<=0；若有限轮后仍违反保护容差，则令 d=0。按累计信赖域缩放 d 并复查保护，拒绝恶化本组线性最大残差的增量，更新 p=p+d。
6. 回溯线搜索 U+alpha*p，重新执行真实 K2 与全部约束计算。只有全部优先级组最大违反程度均不增加（容差内）且至少一组改善，或候选全部内部约束满足时，接受。
7. 满足约束或达到迭代预算、信赖域下限、停滞上限时，返回最后接受的控制和对应执行预测，保留未满足标志。

Stage 1 实际采用近似 LS + 半空间保护，不宣称精确 QP 解。Stage 2 的 `constrained_qp` 后端预留，尚未实现。各物理约束见 `JTP约束定义.md`。
